---
name: Now Playing mentions
description: Mention-notification behavior for requester tags in music playback cards.
---

Show the requester as a Discord user tag in the Now Playing card, but suppress mention notifications for the message.

**Why:** The user finds pings from Now Playing cards disruptive.

**How to apply:** Keep the clickable `<@userId>` display and set the outgoing message's allowed mentions so it does not notify users.
