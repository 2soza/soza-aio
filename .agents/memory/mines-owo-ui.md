Show the player as a tag without sending a notification, and make hidden question-mark tiles the same apparent size as revealed tiles. Keep the configured Fun Economy cash emoji on Cash Out.

**Why:** The user specified a maximum of 8 mines and a default of 3, and wants `smines` to match OwO's presentation rather than a generic embed with buttons underneath.

**How to apply:** Preserve these limits, the payout behavior, and the board's visual rules when changing Mines configuration or interactions.
