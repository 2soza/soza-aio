Mines should use one in-card panel for the status, stats, tile rows, and Cash Out button. Use blue before the first safe pick, green after a diamond is revealed, and gray after a loss. Show the player as a tag without sending a notification, and make hidden question-mark tiles the same apparent size as revealed tiles. Keep the configured Fun Economy cash emoji on Cash Out.

**Why:** The user explicitly wants `smines` to match OwO's presentation rather than a generic embed with buttons underneath.

**How to apply:** Follow these rules when changing Mines layout or interactions; preserve the single-card design and non-pinging mention.
